Place the raw inputs here (or set the environment variable MISSTATE_DATA to the folder that holds them):

* data_FraudDetection_JAR2020.csv — Bao et al. (2020) public dataset (https://github.com/JarFraud/FraudDetection)
* AAER_firm_year.csv — AAER firm-years released with Bao et al. (2020)
* SEC Financial Statement Data Sets, one folder per quarter or year, each containing sub.txt and num.txt
  (https://www.sec.gov/data-research/sec-markets-data/financial-statement-data-sets). File names such as
  "sub (2).txt" are fine: notebook 03 pairs files by filing quarter and verifies each pair.
